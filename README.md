# 오늘 뭐 해먹지

냉장고 재료와 난이도(쉬움·중간·어려움)를 고르면 요리를 추천하고, 재료 손질법과 레시피를 사진과 함께 보여주는 HTML 앱입니다.

**앱 열기:** https://zent1216.github.io/fridge-recipe/

- 레시피 1,170개, 재료 76종, 기본 양념 선택, 부족한 재료 보기, 조리 단계별 사진
- 빌드 없이 동작하는 정적 HTML (`index.html`, `app.js`, `data.js`)
- 입력한 재료는 브라우저에만 저장됩니다

## 레시피 출처

식품의약품안전처 식품안전나라 조리식품 레시피 DB(COOKRCP01)를 사용했습니다. 재료 분류와 난이도는 자동으로 정리했습니다. 갱신은 `tools/build-db.js`로 하며, 인증키는 저장소에 넣지 않습니다.

## 사진 출처

사진은 위키미디어 공용의 자유 라이선스 사진과 일부 AI 생성 이미지입니다. 작성자와 라이선스는 앱의 "사진 출처" 화면과 `credits.json`에 있습니다. 사진이 없는 재료와 요리는 이름 타일로 표시됩니다.
